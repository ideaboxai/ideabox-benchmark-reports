# IdeaBox Benchmark Reports

Public mirror of the rendered HTML reports produced by the monthly
benchmark pipeline in [ideabox-benchmarks](https://github.com/ideaboxai/ideabox-benchmarks)
(private). Only `report.html` for each run date is copied here — no
source code, no raw task transcripts, no credentials.

Browse via [the index page](https://ideaboxai.github.io/ideabox-benchmark-reports/)
or a specific date: `https://ideaboxai.github.io/ideabox-benchmark-reports/<date>/report.html`.
